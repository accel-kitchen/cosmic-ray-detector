# v2 コンソール — 機能の対応表と確認状況

`v2/index.html` の全機能が `v2/console/` のどこに移ったかと、その確認方法の一覧。
通信・行の解析・保存形式・サーバー送信のコードは `js/core.js` に中身を変えずに移してある
（画面に触れていた箇所だけを `settings` / `Bus` / `Hooks` に置き換えた）。

確認の記号:

- **デモ** — デモモードで操作して確認済み（2026-10-07、Chrome、1366×650・1024・768・400 px）
- **比較** — 旧ページと同じ入力を与え、出力がバイト単位で一致することを確認済み
- **実機** — 実機またはネイティブのダイアログが必要。下の「実機で確認すること」に回した

## 実機で確認すること

1. **USB 接続**: 「USBでつなぐ」→ ポート選択 → ヘッダが「接続中 · USB」、検出器の名前が出る。グラフが動く。
2. **ESP32 がダウンロードモードで止まったとき**（`ESP-ROM:` が受信ログに出る）に自動で通常起動するか。
3. **ポートが使用中**（Arduino IDE のシリアルモニタを開いたまま）でメッセージ帯にエラーが出て、閉じられるか。
4. **Bluetooth 接続**: 名前欄を変えて接続できるか。電源を切る／遠ざけると、ヘッダがコーラルで点滅し「◯ 秒後に ◯ 回目の再接続」を数え、戻すと再接続して同じ自動保存ファイルに続けて書くか。
5. **自動保存**: 「保存フォルダを選ぶ」→ `<名前>_<日付>.dat` ができ、件数が増えるか。形式を「.dat と .csv」にして両方できるか。「保存先を先に選ぶ」から選んでからつないでも同じか。
6. **ダウンロード** .dat / .csv、**PNG 保存**（ヒストグラム・レート）、**.wfm 保存**（オシロ）が保存ダイアログ経由で書けるか。中身が旧ページと同じ形か。
7. **タブを閉じる**とき、未保存のイベントがあればブラウザの確認が出るか。
8. **基板の設定**を実機で一通り: しきい値の設定と自動校正、PWM と Auto PWM（約 8 秒）、トリガーモード 3 種、機能スイッチ 5 つ（OLED の表示・ブザー・振動が実際に変わるか）、ブザー／振動のテスト。
9. **名前を変えて再起動**: 基板が再起動し、新しい名前で表示されるか。次回の Bluetooth 接続で新しい名前が使われるか。
10. **オシロスコープ**: 確認ダイアログ → 画面が夜色になり「計数停止中」が数える → 閉じると計数が戻り、閉じている間のぶんがデッドタイムに入っているか（統計 > 総デッドタイム）。Bluetooth 接続中は注意文が出るか。
11. **別の基板**につなぎ替えると、メッセージ帯に「別の検出器につながりました」が出るか（基板 2 枚）。
12. **サーバー送信**: ログイン → 送信開始 → 件数が増える → 停止 → ログアウト。http:// の URL で警告が出るか。
13. **Firefox / Safari** で開くと、USB と Bluetooth のカードが無効になり理由が出るか。
14. **1366×768 のノート PC** の Chrome（ブラウザ枠込み）で、計測画面の数値・グラフ 2 枚・下の 1 行がスクロールなしで見えるか。
