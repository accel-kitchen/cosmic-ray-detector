CosmicRay Recorder

アプリ版をダウンロードする

何時間・何日も続けて記録したい人のための、パソコンに入れて使う版です。画面と使い方はこのページ（ブラウザ版）とまったく同じで、すべての検出器（OWAN v1、OHASHI v2、v2.1、OKOME）に使えます。

いま開いているのは、アプリ版です。

新しい版が出たときは、ここから入れ直してください。

違いブラウザ版との違い

  • ウィンドウを閉じても記録を続けます。画面の右下（Mac は上）のアイコンに残り、止めるときはそのアイコンから「終了」を選びます。
  • 記録中はパソコンをスリープさせません。ほかのアプリを使っていても、裏で記録が間引かれません。
  • 起動したら、前回の検出器に自動でつなぎます。USB を差し直したときも、つなぎ直します。
  • 起動するとすぐ自動保存が始まります。保存先は「書類」の中の CosmicRay フォルダです（変えられます）。
  • パソコンにログインしたら自動で起動するようにもできます（Windows のインストール版と Mac 版）。

少し記録するだけなら、今までどおりブラウザ版で十分です。インストールの要らないブラウザ版は、これからも同じように使えます。

Windowsお使いのパソコン

Windows 10 / 11（64 ビット）。

インストール版（ふつうはこちら）

自分のパソコンで毎日使う人に。スタートメニューから起動でき、ログインしたときに自動で起動させることもできます。

Windows 版（インストール版）をダウンロード

CosmicRayConsole-Setup.exe

ポータブル版（インストール不要）

インストールできないパソコン（学校のパソコンなど）や、USB メモリに入れて持ち歩きたい人に。ダウンロードした exe をダブルクリックするだけで動きます。設定と記録したデータは、exe と同じフォルダの CosmicRayConsole-data と CosmicRay に置き、パソコンには残しません。起動に数秒かかります。

Windows 版（ポータブル版）をダウンロード

CosmicRayConsole-Portable.exe

Macお使いのパソコン

お使いの Mac のチップに合わせて選びます。アップルメニュー →「この Mac について」の「チップ」が Apple M1・M2・M3・M4… なら Apple シリコン版、Intel なら Intel 版です。

Mac 版（Apple シリコン）をダウンロード Mac 版（Intel）をダウンロード

CosmicRayConsole-mac-arm64.dmg ・ CosmicRayConsole-mac-x64.dmg

ダウンロードした dmg を開き、CosmicRay Console を「アプリケーション」フォルダへドラッグします。

はじめてはじめて開くとき

このアプリは、Microsoft や Apple の有料の署名（発行元の証明）を受けていません。そのため、はじめて開くときだけ、パソコンが確認の画面を出します。中身は、このページと同じコンソールです。

Windows

  1. 「Windows によって PC が保護されました」と出たら、詳細情報を押します。
  2. 実行を押します。2 回目からは出ません。
  3. ブラウザがダウンロードを止めたときは、ダウンロードの一覧で 保存（または 保持する）を選びます。

Mac

  1. 「アプリケーション」フォルダの CosmicRay Console をダブルクリックします。「開けません」と出たら、完了（または OK）で閉じます。
  2. 「システム設定」→「プライバシーとセキュリティ」を開き、下のほうの「CosmicRay Console はブロックされました」の横の このまま開くを押します。
  3. もう一度開いて、開くを押します。2 回目からは出ません。
  4. 「壊れているため開けません」と出るときは、「ターミナル」で次の 1 行を実行してから開き直します。
    xattr -cr "/Applications/CosmicRay Console.app"

使い方アプリ版の使い方

  • つなぐ：はじめてのときは、ブラウザ版と同じく「USB で接続」（または Bluetooth）を押して、検出器を選びます。次からは、起動しただけで同じ検出器につながります。
  • 止める・終わる：ウィンドウの × は「隠す」だけです。記録をやめるときは、画面の右下（Mac は上のメニューバー）の紋章のアイコンを押して終了を選びます。検出器との接続を切ってから終わるので、検出器はそのまま数え続けます。
  • 設定：同じアイコンのメニューで、保存先、自動でつなぐか、スリープさせないか、ログイン時に起動するかを切り替えられます。
  • ファームウェアを書き込むとき：アプリは検出器をつかんだままにしています。書き込みや Arduino IDE を使う前に、アプリで「切断」するか、終了してください。
  • ノートパソコン：ふたを閉じるとスリープしてしまいます。長く記録するときは、ふたを開けたままにするか、電源の設定で「ふたを閉じたときの動作」を変えてください。

アプリ版は、ブラウザ版とは別に設定（機種の選択など）を持ちます。作り方とソースは GitHub にあります。
