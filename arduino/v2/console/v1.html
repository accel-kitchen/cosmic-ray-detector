接続オプション

デモの機種
  1. 1
    つなぐUSB か Bluetooth で検出器とつなぎます。
  2. 2
    測る宇宙線が届くたびに、グラフが育っていきます。
  3. 3
    保存する保存フォルダを選ぶと、自動でファイルに記録されます。

Chrome か Edge で動きます。Bluetooth は https:// か localhost で開いたページでだけ使えます。

      ヘルプ
      
    
        
      
          
    • Chrome か Edge で動きます。
      • 
          
    • USB は Web Serial API（9600 bps）を使います。
      • 
          
    • Bluetooth は ESP32-S3 版の検出器だけが使えます。
      • 
          
    • Bluetooth は https:// か localhost で開いたページでだけ使えます。
      • 
          
    • ADC の範囲は、Arduino Nano が 0〜1023（10 ビット）、ESP32-S3 が 0〜4095（12 ビット）です。
      • 
          
    • v1 基板専用です。v2 基板は「機種を選び直す」から v2 を選んでください（列の並びが違います）。
