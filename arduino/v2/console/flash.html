CosmicRay Recorder

ファームウェアを書き込む

検出器を USB でつないで、下のボタンを押すだけで最新のファームウェアを書き込めます。Arduino IDE もアカウントも要りません。

v2 基板（ESP32-S3）

v2.1 の基板には使えません。基板に「v2.1」と印刷されている場合は、上の v2.1 のタブを選んでください。

このブラウザは USB 接続の書き込みに対応していません。Google Chrome か Microsoft Edge をパソコンで開いてください（スマートフォン、Firefox、Safari は使えません）。 https:// で開いたページでないと書き込みできません。配布されている URL から開いてください。

ファームウェア：cosmicray-v2.bin ・ 版 … ・ …

v2.1 基板（ESP32-S3）

基板が v2.1 の検出器（FW 2.1.x）に書き込みます。記録のページで機種に「v2.1」を選んだ検出器が、これにあたります。

v2 の基板には使えません。

v2 と v2.1 は、トリガーやしきい値に使うピンが違います。v2 のファームを v2.1 の基板に、v2.1 のファームを v2 の基板に書き込まないでください。

このブラウザは USB 接続の書き込みに対応していません。Google Chrome か Microsoft Edge をパソコンで開いてください（スマートフォン、Firefox、Safari は使えません）。 https:// で開いたページでないと書き込みできません。配布されている URL から開いてください。

ファームウェア：cosmicray-v21.bin ・ 版 … ・ …

下の「書き込みのしかた」の手順は、v2 と同じです。書き込めたかどうかは、記録のページで起動のメッセージ Booting v2.1... が見えるかで確かめます。

OKOME（お米）— キーホルダーの検出器（MUON FOB）

マイコンは XIAO nRF52840 です。ESP32 の基板と書き込みの方法が違い、ボタンを押しても、このページから直接は書き込めません。代わりに、ファームウェアのファイルを受け取って、検出器が出す USB メモリのような「ドライブ」にコピーします（専用のソフトは要りません）。

OKOME のファームウェアをダウンロード

ファームウェア：cosmicray-okome.uf2 ・ 版 … ・ …

  1. 上のボタンで cosmicray-okome.uf2 をダウンロードしておきます。
  2. OKOME を USB ケーブルでパソコンにつなぎます。
  3. 基板の RESET ボタンを、2 回続けて素早く（ダブルクリックのように）押します。基板の LED がゆっくり明るくなったり暗くなったりを繰り返して、XIAO-BOOT というドライブがパソコンに現れれば、書き込みモードです。
  4. ダウンロードした cosmicray-okome.uf2 を、そのドライブにコピー（ドラッグ）します。
  5. コピーが終わると、ドライブが自動的に消え、OKOME が新しいファームウェアで再起動します。「ファイルが正しくコピーされていません」のような警告が出ることがありますが、これは正常です。
  6. 記録のページで機種に OKOME を選んで、つなぎます。起動のメッセージ Booting MuonFob v0.1... が見えれば成功です。
XIAO-BOOT のドライブが出ないとき

RESET の 2 回押しの間隔が空きすぎている（または短すぎる）ことが多いです。間をおいて、もう一度試してください。それでも出ないときは、USB ケーブルが「充電専用」でないかも確かめてください。

v1 基板（ESP32-S3 Nano 版）

v1 の検出器で、マイコンが ESP32-S3 Nano（Arduino Nano ESP32 など）のものに書き込めます。

マイコンが「Arduino Nano」（ATmega328P）の v1 には使えません。

このページの書き込みは ESP32 専用です。ATmega328P 版の v1 は、マニュアル 付録 D のとおり Arduino IDE で書き込んでください。記録のページの「Arduino Nano（10 ビット）」を選ぶ検出器が、これにあたります。

このブラウザは USB 接続の書き込みに対応していません。Google Chrome か Microsoft Edge をパソコンで開いてください（スマートフォン、Firefox、Safari は使えません）。 https:// で開いたページでないと書き込みできません。配布されている URL から開いてください。

ファームウェア：cosmicray-v1-esp32s3.bin ・ 版 … ・ …

手順書き込みのしかた（ESP32 の基板: v2、v2.1、v1）

  1. 書き込む検出器を USB ケーブルでパソコンにつなぎます。ほかの ESP32 の基板は、USB を抜いておいてください。
  2. 上で機種（OHASHI v2、v2.1、OWAN v1）を選び、書き込みを始めるを押します。
  3. ポートの一覧が出るので、検出器を選んで接続を押します。一覧に 2 つ以上出ていたら、別の基板がつながっています。いったんやめて、抜いてからやり直してください。
  4. インストールを押し、「完了」と出るまで待ちます（1 分ほど）。途中で USB を抜かないでください。
  5. 書き込みが終わったら、記録のページを開いて検出器につなぎます。
書き込みのあとで変わること

検出器に保存してあった設定（Bluetooth の名前、しきい値など）は初期値に戻ります。しきい値は起動のたびに自動校正されます。

この書き込みは、Arduino Nano ESP32 の出荷時の起動プログラムを Espressif 標準のものに置き換えます。そのあとは Arduino IDE の「ダブルタップ → DFU」ではなく、BOOT を押しながら RESET を押す書き込みモードで書き換えます。

困ったときつながらない・書き込めない

  • ポートが一覧に出ない：USB ケーブルが「充電専用」のことがあります。別のケーブルで試してください。
  • 「接続できません」と出る：記録のページや Arduino IDE のシリアルモニタなど、同じ検出器を開いているものを閉じてから、もう一度試してください。
  • それでも書き込めない：BOOT を押しながら RESET を一瞬押して、書き込みモードにしてからやり直します。
  • 書き込み後に何も表示されない：USB をいったん抜いて挿し直してください。記録のページで起動のメッセージ（v2 は Booting v2...、v2.1 は Booting v2.1...）が見えれば成功です。OKOME の手順は、上の OKOME のタブにあります。

自分でスケッチを直したい人は、マニュアル 付録 D の手順で Arduino IDE から書き込みます。
