CosmicRay Recorder · v2 基板

ファームウェアを書き込む

検出器を USB でつないで、下のボタンを押すだけで最新のファームウェアを書き込めます。Arduino IDE もアカウントも要りません。

v2 基板（ESP32-S3）

このブラウザは USB 接続の書き込みに対応していません。Google Chrome か Microsoft Edge をパソコンで開いてください（スマートフォン、Firefox、Safari は使えません）。 https:// で開いたページでないと書き込みできません。配布されている URL から開いてください。

ファームウェア：cosmicray-v2-esp32s3.bin ・ 版 … ・ …

手順書き込みのしかた

  1. 検出器を USB ケーブルでパソコンにつなぎます。
  2. 書き込みを始めるを押します。
  3. ポートの一覧が出るので、検出器（USB JTAG/serial debug unit や Arduino Nano ESP32 などと表示されます）を選んで接続を押します。
  4. インストールを押し、「完了」と出るまで待ちます（1 分ほど）。途中で USB を抜かないでください。
  5. 書き込みが終わったら、記録のページを開いて検出器につなぎます。
書き込みのあとで変わること

検出器に保存してあった設定（Bluetooth の名前、しきい値、PWM、各スイッチ）は初期値に戻ります。しきい値は起動のたびに自動校正されます。

この書き込みは、Arduino Nano ESP32 の出荷時の起動プログラムを Espressif 標準のものに置き換えます。そのあとは Arduino IDE の「ダブルタップ → DFU」ではなく、BOOT を押しながら RESET を押す書き込みモードで書き換えます。

困ったときつながらない・書き込めない

  • ポートが一覧に出ない：USB ケーブルが「充電専用」のことがあります。別のケーブルで試してください。
  • 「接続できません」と出る：記録のページや Arduino IDE のシリアルモニタなど、同じ検出器を開いているものを閉じてから、もう一度試してください。
  • それでも書き込めない：BOOT を押しながら RESET を一瞬押して、書き込みモードにしてからやり直します。
  • 書き込み後に何も表示されない：USB をいったん抜いて挿し直してください。記録のページで Booting v2... が見えれば成功です。

自分でスケッチを直したい人は、マニュアル 付録 D の手順で Arduino IDE から書き込みます。
