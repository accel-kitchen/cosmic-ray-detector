📋 Notes & Tips

  • Works on Chrome / Edge
  • USB: Web Serial API (9600 bps)
  • BLE: Web Bluetooth API
  • BLE requires HTTPS or localhost
  • ADC range is 0–4095 (12-bit)
  • For the v2 board only. v1 boards need v1/index.html (the columns differ).
  • Saved .csv files start with # metadata lines (pandas: read_csv(..., comment='#')).

📉 Oscilloscope

While this tab is open the detector stops counting and streams the peak-hold waveform on A0 (12 us/sample). The time spent here is added to deadtime by the firmware, and the page divides by live time, so the count rate stays correct.

A0 is the peak-hold output, not the raw amplifier pulse. Expect settle -> droop -> reset.

For the v2 detector firmware only. The waveform firmware (COSMICRAY_WAVEFORM_*) does not understand SET_SCOPE; use wave_plotter.html with it.

Over Bluetooth each waveform takes several notifications. Keep the rate low.
