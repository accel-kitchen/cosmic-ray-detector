1. 装置の概要

本装置は SiPM (Silicon Photomultiplier) を用いた宇宙線検出器の v2 基板用ファームウェアです。 SiPM で受けたパルスをアンプ・ピークホールド回路で増幅し、外部コンパレータで閾値判定したものをマイコンが 記録します。さらに 外部 3 系統の検出器（デジタル + アナログ）を接続して同時計測、 コインシデンス判定、音声ジャックへの出力、ブザー鳴動に対応しています。

対応ボード Arduino Nano ESP32 (ESP32-S3)。ボード定義は Arduino IDE の「ボードマネージャ」から esp32 by Espressif Systems を入れると使えます。

2. v1 からの主な変更点

項目v1 (旧)v2 (新)
トリガー方式 ADC を polling し閾値比較 外部コンパレータ + 割り込み。閾値は D2 の PWM Duty で設定
ピークホールド 信号レベルが下がるまで待機 D8 から短いパルスを出して強制リセット
温度センサ NTC サーミスタ (A3, ADC) BME280 (I²C, U4)
コインシデンス Master/Slave 2 台構成 3 台の外部検出器を同時入力 (DIG_IN1-3)
出力インターフェース なし (LED のみ) ブザー、音声ジャック (COIN_OUT, ANA_OUT)
ログ Mode 欄 (Master/Slave) Dig1-3 / Ana1-3 欄を末尾に追加

注意: ANA_OUT はマイコンから見ると入力です ネット名「ANA_OUT」はアナログ前段 (ピークホールド) からの出力の意味で、音声ジャックと マイコン A0 の両方に同じ信号が繋がっています。マイコンはこの電圧を ADC で読み取るだけで、 出力はしません。

3.2 信号の流れ (簡易図)

  SiPM → アンプ → ピークホールド ─┬─ A0 (ADC 読取)
                                    └─ 音声ジャック (ANA_OUT)

  ピークホールド ─ コンパレータ ─ D0 (割込入力: Trigger)
                      ↑
                      PWM Duty (D2) で閾値設定

  D8 (TriggerReset) ─ パルス → ピークホールドをクリア

  外部検出器1-3 ─ DIG_IN1-3 (D6/D5/D4) / ANA_IN1-3 (A1/A2/A6)

  コインシデンス成立 → D7 (COIN_OUT) パルス & D1 (ブザー) 鳴動

4. 開発環境のセットアップ

4.1 必要なもの

  • Arduino IDE 2.x (または PlatformIO)
  • ESP32 Arduino Core (ボードマネージャから)
  • USB Type-C ケーブル (Nano ESP32 用)

4.2 必要ライブラリ

Arduino IDE の「ライブラリマネージャ」で以下を検索してインストールしてください。

ライブラリ名用途
Adafruit SSD1306OLED ディスプレイ
Adafruit GFX Libraryグラフィックス基盤
v2 新規Adafruit BME280 Library温度・気圧・湿度センサ
v2 新規Adafruit Unified SensorBME280 の依存
BLE と Preferences は ESP32 Arduino Core に含まれるので追加インストール不要です。

4.3 ボード設定

  1. Arduino IDE → ツール → ボード → Arduino Nano ESP32 を選択
  2. USB CDC On Boot を Enabled に設定 (USB シリアルが使えるようになる)
  3. ポートは Nano ESP32 を USB 接続後、COMxx (Win) / /dev/cu.usbmodem... (Mac) を選択

5. ファームウェアの書き込み

  1. 本ディレクトリ内の COSMICRAY_DETECTOR_ESP32-S3-Nano-v2.ino を Arduino IDE で開く
  2. 左上の ✓ (検証) ボタンでコンパイル
  3. → (アップロード) ボタンで書き込み
  4. 書き込み完了後、シリアルモニタ (9600 baud) を開くと "Booting v2..." と表示される
初回書き込み時の注意 Nano ESP32 がブートローダモードにならない場合、ボード上の BOOT ボタンを押しながら RESET を一瞬押してください。その後 IDE からアップロードが可能になります。

6. 起動と基本操作

6.1 起動時のシーケンス

  1. 電源 ON → シリアルで "Booting v2..." 出力
  2. Preferences から閾値を読込 (初回は自動校正)
  3. BLE 広告開始: デバイス名 "CosmicRay"
  4. OLED にオープニング画面 (2 秒)
  5. BME280 を探索 (0x76 → 0x77)
  6. D0 に割込登録 → 計測開始

6.2 OLED 表示

8. コマンドリファレンス

シリアル (9600 bps) または BLE RX 特性への書き込みでコマンドを送ります。改行 (LF または CR) で確定します。

GET_THRESH

現在の閾値と PWM Duty を THRESH:<sig> DUTY:<duty> の形式で返します。

SET_THRESH:<signal>

閾値を 0-1023 の範囲で設定し、即座に PWM Duty に反映・Preferences に保存します。

例: SET_THRESH:100 → Duty ≒ 25

v1 から仕様変更: カンマ区切りの 2 引数 (SET_THRESH:sig,rst) は廃止。 RESET_THRESHOLD はハードウェアコンパレータが担当するため不要です。
AUTO_THRESH

A0 (ANA_OUT) のノイズフロアを 100 サンプル測定し、最小値 + 40 を閾値として自動設定します。 ダーク環境で一度実行してください。

SET_SD:ON|OFF / SET_EXT:ON|OFF / SET_OLED:ON|OFF / SET_BUZZER:ON|OFF

各機能をランタイムで ON/OFF し、Preferences に保存します (次回起動時も維持)。 SET_BUZZER:OFF で検出時のビープ音を消せます。デフォルトは全て ON。

状態取得は GET_SD / GET_EXT / GET_OLED / GET_BUZZER。 応答は SD:ON / BUZZER:OFF のような形式で返ります。

9. BLE 接続方法

9.1 プロトコル: Nordic UART Service (NUS)

UUID用途
6E400001-B5A3-F393-E0A9-E50E24DCCA9EService
6E400002-...RX (スマホ→デバイス、Write)
6E400003-...TX (デバイス→スマホ、Notify)

9.2 接続手順

  1. スマホに汎用 BLE ターミナルアプリをインストール
    • iOS: Bluefruit Connect (Adafruit)
    • Android: Serial Bluetooth Terminal または nRF Connect
  2. アプリで "CosmicRay" を検索して接続
  3. UART / Nordic UART モードを選択
  4. イベントログが自動で流れてくる。入力欄からコマンド送信可能
送信の仕組み BLE Notify は 20 バイトごとにチャンク分割して送ります (BLE スタックの制約)。受信側では自動的に 結合されるので気にする必要はありません。

10. トラブルシューティング

シリアルに何も出ない / "Booting" が表示されない
  • ボード種別が Arduino Nano ESP32 になっているか確認
  • USB CDC On Boot が Enabled か確認
  • ボーレートを 9600 に合わせる
  • BOOT + RESET で強制ブートローダに入れて再書込
OLED が真っ黒のまま
  • I²C 配線 (SDA=A4, SCL=A5) と電源 (3.3V / GND) を確認
  • OLED アドレスが 0x3C か (一部は 0x3D)
  • コード中の display.begin(SSD1306_SWITCHCAPVCC, 0x3C) を書き換え
BME280: not found とシリアルに出る
  • BME280 の I²C アドレスは 0x76 または 0x77。モジュールの SDO 端子次第
  • プルアップ抵抗が I²C バスに入っているか (通常 OLED 側に実装済み)
  • BME280 ではなく BMP280 (温度+気圧のみ) の場合は別ライブラリが必要
イベントが 1 回も記録されない
  • 閾値が高すぎる: AUTO_THRESH で再校正
  • コンパレータ出力 (D0) が来ているか、オシロで確認
  • D0 (ESP32-S3 GPIO44) の割込が動作しているか: テストで attachInterrupt 直後に triggerFlag = true を 強制セットして単発イベントが出るか確認
Dig1-3 が常に 0 (または 1)
  • 外部検出器側の出力レベル (3.3V / 5V) とスレッショルド互換性を確認
  • プルアップ/プルダウンの要否を基板回路図で確認。必要ならコード中 pinMode(DIG_IN_PINS[i], INPUT_PULLUP); または INPUT_PULLDOWN に変更
レート (Rate) が異常に高い
  • 閾値 Duty が低すぎて常時トリガーしている可能性
  • ピークホールドリセットパルス (D8) が効いていない: 配線確認
  • D0 にノイズが乗っている: グラウンド配線を見直し、PWM D2 の周波数を上げる

11. 用語集

SiPM
Silicon Photomultiplier。半導体光電子増倍管。微弱な光 (宇宙線のチェレンコフ/シンチレーション光) を検出する素子。
ピークホールド
パルス信号のピーク電圧を一時的に保持するアナログ回路。マイコンが落ち着いて ADC で読むための前段。
コインシデンス
複数の検出器で同時 (∼μs オーダー) にトリガーが出る現象。宇宙線のような貫通粒子の確度を上げるのに使う。
Duty
PWM 信号で HIGH になっている時間の比率。0-255 (8 bit) で表現。Duty × (電源電圧 / 255) ≈ 平均電圧で、コンパレータの閾値生成に使う。
デッドタイム
1 イベントの処理中は次のトリガーを取りこぼす時間帯。レート計算の際に観測時間から差し引く必要がある。
BLE / NUS
Bluetooth Low Energy / Nordic UART Service。スマホから無線でシリアル通信するためのプロファイル。
