# v2 検出器 円柱ケース + LEDリングベース

`cad/build_compact_enclosure.py` の角形ケースを円柱に置き換えたものです。内部の配置は角形ケースと同じで、外形だけが丸く、床が別部品（底板）になっています。上蓋に `../ring-base/ring-base-lidmount.stl` をネジで固定します。STLの単位はmmです。導光部品は使いません。

上蓋とリングベースの中央には、LEDリングより大きいφ50 mmの穴が貫通しています。リングは、外せる「リング座」の上に載ります。リング座を持ち上げて外すと、リングはケーブルが付いたまま上蓋の穴を通って筒の中へ下ろせます。上蓋はネジで止めたままで構いません。

## 寸法

- ケース外径 **113.2 mm**（内径108.4 mm、壁2.4 mm）、ケース高さ59.0 mm、上蓋込みで61.4 mm
- リングベース：直径72 mm（以前は80 mm）、**ボス直径70 mm**、全高18 mm。載せた全高は79.4 mm
- 上蓋とリングベースの貫通穴：**φ50 mm**（仮置きのリング外径44.5 mmに片側2.75 mmの余裕）。リングの寸法を直すと、穴も自動で追従します（`RING_OD` + 5.5 mm）
- リング座：直径55.6 mm、厚さ4 mm。リングベース上面のφ56 mm・深さ4 mmの座ぐりに入り、穴の周りの幅3 mmの段に載ります。上面はボスの上面と同じ高さです
- 外径は、角形ケース内側の長方形の対角線（107.3 mm）に0.5 mmの余裕を足して決めました。角形ケースに収まったものは円にも収まります。
- 基板のスペーサ穴、蓋ネジ位置（4本）、USB・OLED窓・RESET・オーディオの開口位置と大きさは角形ケースと同じです。
- 前面のLED穴（基板のLED1用）は開けたままです。導光部品を使わないので、不要なら塞いでください。
- 6ピンコネクタ（J4）・microSD（J8）・ゲイン調整トリマ（R10）の開口を追加しました（次の節）。

## 6ピン・microSD・ゲイン調整の開口

基板（`cosmic-ray-detector.kicad_pcb`）から位置と向きを読んで決めました。J4・J8・R10はどれも基板の**下面**にあります。

| 部品 | 場所と向き | 開口 |
| --- | --- | --- |
| J4（JST XH 6ピン、サイド挿入。5V・CS1・GND・MISO・MOSI・SCLK） | 基板の−X端（x=41、y=62.6〜82.2）。プラグは−X側から差す | −X側の壁に窓（y 62.6〜83.0、基板下面から高さ −10〜+6.5 mm） |
| J8（microSD） | 基板の−X端（y 82.6〜98.0）。カードは−X側から入る（旧版はオーディオ側から届くと書いていましたが、向きが違いました） | J4の窓につながる窓（y 80〜96.5、高さ −4.6〜+6.5 mm） |
| R10（ゲイン調整トリマ） | 基板下面。調整ネジの溝が**下**を向く。軸はKiCad (62.0, 69.54) | 底板に直径6.0 mmの穴（スペーサのネジ穴との間に2.1 mmの壁が残る） |

- 2つの窓は1つの開口にまとまっています。USBの開口との間には3.0 mmの壁が残ります。
- **手が届く深さ**：コネクタの口から壁の内側まで、J4は約19 mm、microSDは約14 mmです。窓を通して指先とプラグ（ケーブルを持つ）で差し込めますが、microSDは指では奥まで押し込めません。ピンセットか細い棒が要ります。
- トリマ：ネジ面から底板の上面まで約12 mmあります。直径3 mm程度のドライバーで届きます。穴は真っすぐ上向きです。
- 底板を外さずに、外からドライバーを入れて回せます。回す向きと量は、実機で信号を見ながら決めてください。
- **高さ方向は未確認です**。J4とmicroSDの背の高さはデータシートや実物では確認していません（J4は約6 mm、microSDは約2 mmと見込んでいます）。角形ケースの実物合わせで、側面の開口を基板モデルより3 mm上に動かした経緯があるので、窓の上端を3 mm上げ（+3.5 → +6.5 mm）、基板モデルどおりの高さと3 mm上の両方でプラグとカードが通ることを確認しています。実物で合わなければ `build_compact_enclosure.py` の `J4_WIN_*`・`SD_WIN_*` を直してください（開口の定数は角形ケースと共通です）。
- 角形ケース（`build_compact_enclosure.py`）にも同じ開口を付けました。角形は壁が近いので、コネクタの口から壁の内面まで約5.6 mmで、指で差し込めます。

## リングのケーブル

リングとケーブル、ケーブルと基板は、どちらもハンダ付けで外せません。そこで、リングがケーブルごと通れる大きな穴（φ50）を上蓋とリングベースに開け、リングはその上に置く別部品の**リング座**に載せる形にしました。

- リング座の上面に、リングの凹み（φ45.1、深さ1.6 mm）と中心の位置決め柱があります。これまでのリングベース上面と同じ形です。
- ケーブルはリングの**真下**に出るので、リング座のケーブル穴は、リングの環の真下にある細長い穴（長さ16 × 幅7 mm、軸から半径19.5 mm）です。穴の下はφ50の貫通穴なので、ケーブルはそのまま上蓋の下へ抜けます。
- リング座には、ケーブル穴から外周まで**スリット**（幅6 mm）があります。ケーブルの両端がハンダ付けでも、リング座を横からケーブルにはめられます。
- リングは座の中で回せます。ハンダ付け部をケーブル穴の上に合わせてください。穴はハンダ付け部の逃げも兼ねます。リング座も座ぐりの中で回せます。
- 座ぐりの縁の2か所（±X側）に切り欠き（φ10、リング座より1.5 mm深い）があります。細いマイナスドライバーをここに差し込んで、リング座を持ち上げます。
- リングとリング座は載せるだけで、固定しません（剥がせる両面テープなら可）。球状のカバーを上に載せれば、押さえにもなります。
- 上蓋とリングベースの側面にあったスリットは無くしました。リングが穴をまっすぐ通るので、要らなくなりました。
- ケーブルの長さ：取り付けのとき、基板を筒に入れたままリングをリングベースの上より30 mmほど高く引き上げられる長さが要ります。J4から測って約120 mmなので、**150 mm以上**（200 mmあれば余裕）を目安にしてください。余りは筒の中に収まります。

## 基板を外す

**リング・ケーブル・基板を全部外す**（ハンダ付けのまま、1つの塊として。上蓋は止めたままでよい）

1. リングを持ち上げ、続けてリング座を切り欠きから持ち上げます。リング座をケーブルからスリットで横に外します。
2. リングを上蓋の穴（φ50）から筒の中へ下ろします。
3. ケースを逆さにして、底板のM2×8 mmネジ4本（底板の裏側、沈め座ぐり付き）を外します。USB・オーディオのケーブルは先に外してください。
4. 底板ごと基板を下へ引き出します。リングもケーブルにつながったまま、一緒に筒の下から出てきます（リングは筒の内径108.4 mmより小さく、筒の内側には蓋ネジ用と底板ネジ用の柱しかありません）。

**基板だけ下へ出す（リングは上に載せたまま）**：ケーブルに余裕がある場合だけです。リングを座に載せたまま底板のネジを外し、ケーブルが届く範囲で基板を下へ引き出せます。

**取り付け**（ケーブルの両端が外せないので、この順番で）

1. 基板を底板に付け、リングを基板の上に載せて、底板ごと筒の下から押し込みます。底板をM2×8 mm 4本で止めます。上蓋とリングベースは先に付けておいて構いません。
2. 上蓋の穴（φ50）から指を入れてリングを持ち、穴を通して上へ引き上げます。
3. リングを持ち上げたまま、リング座をスリットからケーブルにはめ、座ぐりへ落とします。
4. リングをリング座に載せ、ハンダ付け部がケーブル穴の上に来るように回します。

手順1でリングを中に入れられるのは、シンチレータの上面から上蓋の裏まで約14.8 mmの空きがあるためです（以前、部品モデルで確認した値。リングは部品込みで約3.2 mm）。中でリングをつかみにくい場合は、上蓋を外した順番でも組めます。リングを筒の下から入れて上端から出し、底板を止めてから、上蓋（リングベース付き）の穴にリングを下から通して上蓋を筒に載せ、M2ネジで止めます。その後、手順3〜4を行います。

## ネジ

- 蓋とケース：M2ネジ4本（角形ケースと同じ。ネジ頭は蓋の上面、リングベースの外側に出ます）
- 底板と筒：M2×8 mm 4本（底板の裏側から、筒の柱の下穴へ）
- リングベースと蓋：M3×8 mm 3本を蓋の裏側から通し、リングベース下面の下穴へねじ込みます（軸から半径31 mm、リングベースの座標で90°・210°・330°。リングベースを72 mmにしたときに34 mmから内側へ移しました）。リングベースには側面のスリットが無くなったので、3通りのどの向きで止めても構いません。リングベースは一度止めたら外す必要はありません（リングの出し入れはリング座を外して行います）。

## 確認できたこと・できていないこと

- 筒・底板・蓋とも、閉じた単一のメッシュです。筒・底板・蓋の相互の干渉はありません。
- 角形ケースの空き空間に、筒・底板・蓋の材料が入り込んでいないことを体積で確認しました。内側の形は変わっていません。
- 底板ネジ4本の通り道が、底板から柱の下穴までふさがれていないことを確認しました。基板が下へ抜けるのを妨げる新しい出っ張りが、長方形の内側に無いことも確認しました。
- 各開口が内側から外側まで貫通していることを確認しました。J4のプラグとmicroSDのカードの通り道（基板モデルの高さと3 mm上の両方）がコネクタの口（x=41）から外まで、直径5.8 mmの円柱がトリマへ真下から届く通り道も、ふさがれていないことを確認しました。新しい窓が、底板ネジの柱と蓋ネジの柱を削っていないことも確認しました。
- リングベースとリング座を蓋に載せた状態で、次のことを確認しました。
  - リング座がリングベース・上蓋と重ならず、段の上に載っていること
  - リング座を外すと、リングより1 mm大きい円盤（φ45.5）が、リングベース・上蓋・筒をまっすぐ下まで通ること（リング座を入れると通らないことも確認し、検査が失敗し得ることを確かめています）
  - リング座のケーブル穴から、リングベースと上蓋を通って蓋の下まで、ケーブルの通り道がふさがれていないこと。幅4.4 mmのケーブルが、リング座のスリットを通って外周まで抜けること
  - M3ネジ3本の通り道がふさがれていないこと。蓋のM3穴とφ50の穴の間に4.3 mm、リングベースの下穴と穴の間に4.7 mmの肉が残ること
  - 以前、蓋のM3穴の並びが鏡像になっていた不具合がありました。鏡像の並びだと確認が失敗することも検査しています。
- M3の頭（上蓋の裏側、ケース内に約2〜3 mm出る）は、リングベースを72 mmにしたことで軸側へ3 mm寄りました。以前の部品モデルでの確認では、シンチレータの上面から上蓋の裏まで約14.8 mmあるので当たらない見込みですが、今回の位置では確認し直していません（次の項目の理由）。
- **部品ごとの干渉確認は再実行していません。** 検出器の3Dモデル（`lp/assets/model/detector-pack.js`）がこのリポジトリになく、v2.1のものはハッシュが違うためです。
- リングの外形は仮置き（外径44.5 / 内径31.7 / 基板厚1.6 mm）です。実物を測って `../build_ring_base.py` の `RING_*` を直してください。φ50の穴は `RING_OD` から決まるので、直せば穴も変わります。ケーブルの付け根とハンダが、リングの外径からはみ出していないか（はみ出すと穴を通りにくい）、軸から16〜23 mm、円弧に沿って16 mmの範囲に収まるかも確認してください。
- 上蓋の中央に大きな穴が開いたので、リング座を外している間は筒の中が上から見えます。リング座を入れれば、穴はケーブル穴とスリットの分を除いて塞がります。
- ケーブル長150 mmは、J4の位置と高さからの見積もりです。実物では測っていません。
- **円柱にしたことで、壁が角形より外にあります。** RESETの軸の先から壁の外面までは約9.6 mm（角形は約2.1 mm）あるため、直径7.5 mmの穴は指では届かず、細い棒（ピンなど）が必要です。オーディオジャックとUSBも、プラグが壁の開口を通ってさらに10〜19 mm奥へ届く必要があります。実物のプラグで確認してください。
- 試作・実物の嵌め合いは未実施です。

## 再生成

```powershell
python cad/build_ring_base.py
python cad/build_round_enclosure.py
```

必要なパッケージは `numpy`、`trimesh`、`manifold3d`、`matplotlib`、プレビュー用に `pillow` とBlender 5.2です。
