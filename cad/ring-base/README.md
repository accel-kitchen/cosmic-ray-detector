# LEDリング用 円柱ベース

WS2812 LEDリング（外径68 mm・内径52 mm、2026-11-21に実測）を載せる、直径72 mm・高さ18 mmの円柱ベースです。STLの単位はmmです。

| ファイル | 内容 |
| --- | --- |
| `ring-base.stl` | 単体で机に置く版。下面にゴム足用の凹み |
| `ring-base-lidmount.stl` | 円柱ケースの上蓋にひねって固定する版（ネジなし）。下面に爪付きの突起 |
| `ring-base-preview.png` | 上蓋版の3D、上面図、単体版と上蓋版の断面 |
| `ring-base-validation.json` | メッシュ検査と主要寸法 |
| `../build_ring_base.py` | 寸法変更・STL再生成用 |

以前あった `ring-base-seat.stl`（リング座）は、リングの実寸が分かって形を変えたため廃止しました。

## 寸法（2つの版で共通）

- 本体：直径72 mm（以前は80 mm）、高さ18 mm、上縁に0.5 mmの面取り。以前の「ボス」の段は無くしました（φ68のリングを載せると、φ70のボスでは外周の肉が0.7 mmしか残らないため）
- リングの凹み：上面に外径68.6 mm・深さ1.6 mmの環状の凹み。中心に直径51.4 mmの位置決め柱（リングの穴に入る）。凹みの外側の肉は1.7 mm
- ケーブル穴：リングの環の真下に細長い貫通穴（長さ16 × 幅7 mm、軸から半径30 mm、−X側）。ハンダ付け部の逃げも兼ねます。穴から−X側の外周まで、幅6 mmのスリットが全高を貫通しています（ケーブルの両端がハンダ付けで外せないため、ケーブルを横から出し入れできるように）

**リングの基板の厚さは仮置き**（1.6 mm）です。外径・内径は実測値です。厚さが違えば、`build_ring_base.py` の `RING_PCB` を直して再生成してください。

## 単体版（`ring-base.stl`）

- 下縁に1.5 mmの面取り
- 下面にφ10.2 mm・深さ1.2 mmのゴム足用の凹み4か所（軸から半径27 mm）

## 上蓋にひねって固定する版（`ring-base-lidmount.stl`）

- 下面に直径69.6 mmの突起（高さ4.15 mm）があり、円柱ケースの上蓋の**φ70の穴**を貫通します。本体は穴の縁（幅約0.7 mm）に載ります
- **ひねって固定（バヨネット）。ネジはありません。** 突起の下端に爪が3つ（120°おき、幅20.6°、厚さ1.6 mm）あり、穴の縁から外へ2.5 mm張り出します
  1. 上から見て、スリットが−X側（J4側）より**30°反時計回り**の向きで差し込みます。爪が上蓋の穴の切り欠きを通って下へ抜けます
  2. **時計回りに30°**回します。爪が上蓋の裏に入り、上蓋の裏の止めに当たって止まります。スリットは−X側を向きます
  3. この状態では持ち上げても抜けません（爪と上蓋の裏の隙間は0.15 mm）。外すときは反時計回りに30°戻して持ち上げます
- 外したあと、ケーブルをスリットから横へ抜けば、リングはφ70の穴（リングより片側1 mm大きい）を通ってケースの中へ下ろせます
- 下縁の面取りは0.3 mm（縁に載る幅を残すため）
- 回った位置で止める「カチッ」とした手応え（戻り止め）はありません。固定中は止めと爪で位置が決まり、戻すには手で反時計回りに回す必要があります

使い方と組立順は `../round-case/README.md` を参照してください。

## 印刷と組立（単体版）

1. STLの向きのまま、底面をベッド側にして印刷します。サポートは不要です（ケーブル穴とスリットは全高を貫通しています）。上蓋版は突起を下にして印刷します（爪もベッド側なのでサポート不要。突起と本体の段差は片側1.2 mm）。
2. リングの線を、リング真下の細長い穴へ横のスリットから入れ、穴の下へ出します。
3. リングをLEDを上にして凹みへ入れ（回してハンダ付け部を穴の上に合わせる）、必要なら剥がせる両面テープで固定します。
4. 配線は ringLED ファームウェアの記載（J4-1 GND、J4-2 5V、J4-4 CS1 → 330 Ω → DIN）に従います。
