# LEDリング用 円柱ベース

16連 WS2812 5050 LEDリング（AliExpress 1005010000373922）を載せる、直径72 mmの円柱ベースです（以前は80 mm）。STLの単位はmmです。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `ring-base.stl` | 単体で机に置く版（1個） |
| `ring-base-lidmount.stl` | 円柱ケースの上蓋に止める版。中央にφ50の貫通穴（下の節） |
| `ring-base-seat.stl` | 上蓋版で使うリング座（1個） |
| `ring-base-preview.png` | 単体版の3D・上面・断面と、上蓋版＋リング座の断面 |
| `ring-base-validation.json` | メッシュ検査と主要寸法 |
| `../build_ring_base.py` | 寸法変更・STL再生成用 |

## 寸法

- ベース：直径72 mm（以前は80 mm）、高さ10 mm、下縁に1.5 mm・上縁に0.5 mmの面取り
- ボス：直径70 mm（球状のカバーが載るように。以前は52 mm）、ベース上面から8 mm（全高18 mm）。ベースとの段差は片側1 mm
- リングの凹み：直径45.1 mm、深さ1.6 mm。中心に直径31.1 mmの位置決め柱
- ケーブル穴：リングの真下に細長い貫通穴（長さ16 × 幅7 mm、軸から半径19.5 mm、−X側）。ハンダ付け部の逃げも兼ねる。中央に穴は無い。穴から−X側の外周まで、幅6 mmのスリットが全高を貫通している（ケーブルの両端がハンダ付けで外せないため、ケーブルを横から入れられるように）
- 下面にφ10.2 mm・深さ1.2 mmのゴム足用の凹み4か所（軸から半径27 mm。80 mmの頃は31 mm）

**リングの寸法は仮置き**（外径44.5 / 内径31.7 / 基板厚1.6 mm）です。商品ページに寸法の記載がありません。実物をノギスで測り、`build_ring_base.py` の `RING_OD` `RING_ID` `RING_PCB` を直して再生成してください。

## 印刷と組立

1. STLの向きのまま、底面をベッド側にして印刷します。サポートは不要です（ケーブル穴とスリットは全高を貫通しています）。
2. リングの線を、リング真下の細長い穴へ横のスリットから入れ、穴の下へ出します。
3. リングをボス上面の凹みへLEDを上にして入れ（回してハンダ付け部を穴の上に合わせる）、接着剤か両面テープで固定します。
4. 配線は ringLED ファームウェアの記載（J4-1 GND、J4-2 5V、J4-4 CS1 → 330 Ω → DIN）に従います。

試作・実物での嵌め合い確認は未実施です。

## 円柱ケースの上蓋に取り付ける版

`ring-base-lidmount.stl` は、単体版と外形（φ72、ボスφ70、全高18 mm）は同じで、次の点が違います。

- 足の凹みは無く、下面にM3用の下穴（直径2.6 mm、深さ6.5 mm、半径31 mm、90°・210°・330°）が3つあります。直径を72 mmにしたとき、外周から穴が出ないように半径を34 mmから31 mmへ寄せました（下縁の面取りまで2.2 mm、中央の穴まで4.7 mmの肉が残ります）。上蓋の裏からM3×8 mmで固定します。
- 中央に**φ50 mmの貫通穴**があります（`RING_OD` + 5.5 mm）。上蓋にも同じ穴があり、リングがケーブルごと上蓋の下へ通れます。
- ボス上面に**φ56 mm・深さ4 mmの座ぐり**があり、別部品の**リング座**（`ring-base-seat.stl`、φ55.6 × 4 mm）が入ります。リング座は穴の周りの幅3 mmの段に載り、上面がボスの上面と揃います。
- リング座の上面にリングの凹み（φ45.1、深さ1.6 mm）、位置決め柱、ケーブル穴（16 × 7 mm）があり、ケーブル穴から外周まで幅6 mmのスリットがあります。
- 座ぐりの縁の2か所（0°・180°）に、リング座を持ち上げるための切り欠き（φ10、リング座より1.5 mm深い）があります。
- 側面のスリットはありません（リングが穴を通るので不要）。

リング座はSTLの向きのまま（凹みを上に）印刷します。サポートは不要です。使い方と組立順は `../round-case/README.md` を参照してください。
