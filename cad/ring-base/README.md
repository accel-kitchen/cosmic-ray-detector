# LEDリング用 円柱ベース

16連 WS2812 5050 LEDリング（AliExpress 1005010000373922）を載せる、直径80 mmの円柱ベースです。STLの単位はmmです。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `ring-base.stl` | ベース本体（1個） |
| `ring-base-preview.png` | 3D・上面・断面の確認図 |
| `ring-base-validation.json` | メッシュ検査と主要寸法 |
| `../build_ring_base.py` | 寸法変更・STL再生成用 |

## 寸法

- ベース：直径80 mm、高さ10 mm、上下縁に1.5 mmの面取り
- ボス：直径70 mm（球状のカバーが載るように。以前は52 mm）、ベース上面から8 mm（全高18 mm）
- リング座：直径45.1 mm、深さ1.6 mm。中心に直径31.1 mmの位置決め柱
- ケーブル穴：リングの真下に細長い貫通穴（長さ16 × 幅7 mm、軸から半径19.5 mm、−X側）。ハンダ付け部の逃げも兼ねる。中央に穴は無い。穴から−X側の外周まで、幅6 mmのスリットが全高を貫通している（ケーブルの両端がハンダ付けで外せないため、ケーブルを横から入れられるように）
- 下面にφ10.2 mm・深さ1.2 mmのゴム足用の凹み4か所

**リングの寸法は仮置き**（外径44.5 / 内径31.7 / 基板厚1.6 mm）です。商品ページに寸法の記載がありません。実物をノギスで測り、`build_ring_base.py` の `RING_OD` `RING_ID` `RING_PCB` を直して再生成してください。

## 印刷と組立

1. STLの向きのまま、底面をベッド側にして印刷します。サポートは不要です（ケーブル穴とスリットは全高を貫通しています）。
2. リングの線を、リング真下の細長い穴へ横のスリットから入れ、穴の下へ出します。
3. リングをボス上面の凹みへLEDを上にして入れ（回してハンダ付け部を穴の上に合わせる）、接着剤か両面テープで固定します。
4. 配線は ringLED ファームウェアの記載（J4-1 GND、J4-2 5V、J4-4 CS1 → 330 Ω → DIN）に従います。

試作・実物での嵌め合い確認は未実施です。

## 円柱ケースの上蓋に取り付ける版

`ring-base-lidmount.stl` は、足の凹みを無くし、下面にM3用の下穴（直径2.6 mm、深さ6.5 mm、半径34 mm、90°・210°・330°）を3つ開けた版です。上蓋の裏からM3×8 mmで固定します。詳しくは `../round-case/README.md` を参照してください。
